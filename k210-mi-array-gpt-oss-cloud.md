Script MicroPython para el módulo K210 (Yahboom Development Board)
Objetivo:

Inicializar la pantalla LCD.
Configurar la cámara (sensor OV‑2640 integrado).
Inicializar la matriz de micrófonos Sipeed R6+1 (6 + 1 MEMS).
Obtener en cada iteración el mapa de intensidad sonora (8 × 8) y calcular la energía en cada lado del rectángulo (izquierda, derecha, arriba, abajo).
Dibujar un rectángulo central sobre la imagen de la cámara y, en cada borde, una barra cuyo tamaño es proporcional a la intensidad del sonido proveniente de esa dirección.
Mostrar el resultado en la LCD.
El código está pensado para MaixPy v1/v2 y aprovecha el KPU (puede usarse más adelante para inferencia de IA, aunque aquí no se necesita).

# -*- coding: utf-8 -*-
# ------------------------------------------------------------
# K210 + Yahboom Board + Sipeed R6+1 Microphone Array
# Muestra la cámara y visualiza la dirección del sonido con barras
# ------------------------------------------------------------

import sensor, image, lcd, time
from Maix import MIC_ARRAY as mic                 #  ← API de la matriz de micrófonos
# from Maix import KPU                         # <-- disponible para NN (no usado aquí)

# ------------------------------------------------------------------
# 1. LCD -----------------------------------------------------------
# La función `lcd.init()` acepta los mismos parámetros que en la
# documentación oficial【36†L24-L28】.
lcd.init(type=1, freq=15000000, color=lcd.BLACK)   # LCD shield, 15 MHz SPI, fondo negro
lcd.rotation(0)                                   # 0‑3 para girar la pantalla

# ------------------------------------------------------------------
# 2. Cámara --------------------------------------------------------
sensor.reset()                                    # reinicia el sensor
sensor.set_pixformat(sensor.RGB565)               # color (16‑bit)
sensor.set_framesize(sensor.QVGA)                # 320 × 240 → igual al LCD
sensor.skip_frames(time=2000)                     # esperar a que la configuración sea estable
# sensor.set_auto_gain(False); sensor.set_auto_whitebal(False)   # opcional

# ------------------------------------------------------------------
# 3. Matriz de micrófonos -----------------------------------------
# Se usan los pines‑por‑defecto que aparecen en la guía de Sipeed
# (23‑18 para I2S y 24‑25 para la anilla LED).  El mismo ejemplo
# está en la documentación de la placa【37†L109-L112】.
mic.init(
    i2s_d0=23, i2s_d1=22, i2s_d2=21, i2s_d3=20,
    i2s_ws=19, i2s_sclk=18,
    sk9822_dat=24, sk9822_clk=25
)

# ------------------------------------------------------------------
# 4. Funciones auxiliares -----------------------------------------
def side_intensity(map_img):
    """
    Suma la intensidad de los píxeles en cada mitad del mapa
    (el mapa es 8×8 según la descripción de `get_map()`【34†L35-L38】).
    Devuelve: left, right, top, bottom.
    """
    w = map_img.width()
    h = map_img.height()
    left = right = top = bottom = 0
    for y in range(h):
        for x in range(w):
            v = map_img.get_pixel(x, y)          # 0‑255
            if x < w // 2:
                left += v
            else:
                right += v
            if y < h // 2:
                top += v
            else:
                bottom += v
    return left, right, top, bottom

def norm(val, max_val):
    """Escala 0‑1 (corte a 1.0)."""
    return min(1.0, float(val) / max_val)

# Valor máximo posible de una mitad del mapa (32 píxeles × 255):
MAX_SIDE = 255 * (8 * 8 // 2)      # 255 × 32 = 8160

# ------------------------------------------------------------------
# 5. Parámetros de visualización ----------------------------------
RECT_X, RECT_Y = 60, 40          # posición del rectángulo
RECT_W, RECT_H = 200, 160        # ancho y alto
RECT_COLOR = (255, 0, 0)        # rojo
RECT_THICK = 2

MAX_BAR = 30                     # longitud máxima de la barra (px)
BAR_COLOR = (0, 255, 0)          # verde
BAR_THICK = 4

clock = time.clock()

# ------------------------------------------------------------------
# 6. Bucle principal -----------------------------------------------
while True:
    clock.tick()

    # ---- Imagen de la cámara ------------------------------------
    img = sensor.snapshot()

    # Dibujar el rectángulo de referencia
    img.draw_rectangle(RECT_X, RECT_Y, RECT_W, RECT_H,
                       color=RECT_COLOR, thickness=RECT_THICK)

    # ---- Mapa de sonido -----------------------------------------
    map_img = mic.get_map()                     # 【37†L115-L118】 devuelve 8×8
    left, right, top, bottom = side_intensity(map_img)

    # Normalizar a 0‑1
    left_n  = norm(left,  MAX_SIDE)
    right_n = norm(right, MAX_SIDE)
    top_n   = norm(top,   MAX_SIDE)
    bottom_n= norm(bottom,MAX_SIDE)

    # ---- Dibujar barras en cada borde ---------------------------
    # Arriba
    top_len = int(MAX_BAR * top_n)
    img.draw_rectangle(RECT_X, RECT_Y - top_len,
                       RECT_W, top_len, color=BAR_COLOR, fill=True)

    # Abajo
    bot_len = int(MAX_BAR * bottom_n)
    img.draw_rectangle(RECT_X, RECT_Y + RECT_H,
                       RECT_W, bot_len, color=BAR_COLOR, fill=True)

    # Izquierda
    left_len = int(MAX_BAR * left_n)
    img.draw_rectangle(RECT_X - left_len, RECT_Y,
                       left_len, RECT_H, color=BAR_COLOR, fill=True)

    # Derecha
    right_len = int(MAX_BAR * right_n)
    img.draw_rectangle(RECT_X + RECT_W, RECT_Y,
                       right_len, RECT_H, color=BAR_COLOR, fill=True)

    # ---- Mostrar en la LCD ---------------------------------------
    lcd.display(img)          # La LCD acepta directamente un objeto Image【31†L24-L28】

    # Pequeña pausa para no saturar la CPU
    time.sleep_ms(20)
Comentarios clave
LCD – lcd.init() con los parámetros recomendados por la API oficial del K210 (CanMV)
[36]
.
Cámara – La secuencia de inicialización (reset, set_pixformat, set_framesize, skip_frames, snapshot) está tomada de la guía de la cámara para MaixPy
[35]
.
Micrófonos – La librería MIC_ARRAY se inicializa como en el ejemplo oficial del fabricante
[37]
. mic.get_map() devuelve un mapa 8×8 de niveles de presión sonora (documentado en Luffca)
[34]
.
Cálculo de intensidad por lado – Se suman los valores de la mitad izquierda/derecha y superior/inferior del mapa. El valor máximo de cada mitad es 255 × 32 = 8160, usado para normalizar.
Visualización – Un rectángulo rojo se dibuja en el centro de la imagen; en cada borde se dibuja una barra verde cuya longitud es proporcional a la intensidad del sonido proveniente de esa dirección.
Este script combina visión y audio en tiempo real, muestra la dirección del sonido con indicadores gráficos y está listo para ejecutarse directamente en el Yahboom K210 Development Board con la Sipeed R6+1 Microphone Array. Si más adelante se desea aplicar inferencia de IA, basta con importar from Maix import KPU y cargar un modelo sobre la imagen capturada.
